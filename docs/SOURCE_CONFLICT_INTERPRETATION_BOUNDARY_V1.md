# Source Conflict Interpretation Boundary v1

## Core rule
When valid Evidence from different sources disagrees, AIRA preserves the disagreement unless an already-approved authority rule resolves that exact claim scope.

## No automatic winner
- newest collection time does not win;
- regulator/exchange/central-bank labels do not create a universal priority across unrelated claim types;
- more Evidence items do not win by majority vote;
- AIRA must not average incompatible values into one synthetic truth.

## Authority-aware resolution
A source may resolve a conflict only when its accepted authority scope explicitly covers the same subject, metric/event, period, and jurisdiction.

## Product meaning
Unresolved disagreement stays visible as conflict/uncertainty with each supporting provenance path available for inspection.

## Restraint
A later source may supersede an earlier claim only through an explicit accepted supersession/revision contract, never because it is merely later.

## Implementation boundary
Conflict-resolution engines, source-priority configuration, UI, and tests are CODEX-FIRST/later work.
