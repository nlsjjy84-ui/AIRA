# Claim / Evidence Presentation Boundary v1

## Core rule
AIRA must not present a factual market/company statement as settled truth unless the supporting Fact/Event/Assessment provenance is inspectable.

## Product meaning
- factual claims expose a path to their supporting Evidence;
- derived/analytical claims distinguish source fact from interpretation;
- CONFLICTING or incomplete provenance must be visible as such;
- unsupported narrative text must not be styled like verified fact;
- source authority labels do not replace actual claim-specific Evidence.

## Restraint
Do not collapse several unrelated Evidence items into a generic `근거 있음` badge.
Do not hide the actual provider/date/period context needed to understand the claim.

## Implementation boundary
Citation components, claim-to-evidence query shape, expandable provenance UI, API payloads, and tests are CODEX-FIRST/later work.
