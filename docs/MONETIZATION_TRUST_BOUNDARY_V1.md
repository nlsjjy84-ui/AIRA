# Monetization / Trust Boundary v1

## Core rule
AIRA's user-facing evidence/analysis experience is not an advertising or sponsored-recommendation surface.

## Settled product meaning
- no ads or sponsored placements inside discovery/analysis flows;
- no paid ranking, paid prominence, or pay-to-be-recommended behavior;
- no recommendation content disguised as neutral evidence;
- core user-facing trust semantics must not change based on commercial relationships.

## Public API
- AIRA may expose a public API under a usage-metered/paid model;
- API billing is a delivery/access policy, not a signal of source quality or product recommendation;
- paid API usage must not alter Fact/Event/Evidence/Assessment truth semantics or ranking;
- commercial/API metadata must remain separate from Evidence provenance.

## Restraint
Revenue mechanisms must never silently influence Source authority, Evidence ordering, Assessment meaning, Briefing/Alert qualification, or MAIN card prominence.

## Implementation boundary
Plans, pricing, quotas, billing integration, API keys, metering, rate limits, and account UI are CODEX-FIRST/later work.
