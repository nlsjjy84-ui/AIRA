# ADR-001: Event 중심 정보 모델

- 상태: Accepted
- 기준일: 2026-08-14

## Context

하나의 시장 사건은 뉴스 기사, 공시, 기업 IR 등 여러 문서에서 반복적으로 다뤄진다. 문서 중심 모델은 같은 사건을 중복 노출하고 분석과 AI 비용을 반복 발생시키며, 사용자가 실제 변화를 파악하기 어렵게 한다.

## Decision

AIRA는 문서가 아니라 `Event`를 정보 모델의 중심으로 사용한다.

- 여러 Source와 Evidence가 같은 사건을 설명하면 가능한 경우 하나의 Event로 통합한다.
- Event와 공개 시장 Entity는 다대다 관계를 갖는다.
- Event에는 매수·매도 지시나 단일 positive·negative 값을 저장하지 않는다.
- 문서 원문과 출처는 Evidence를 통해 추적한다.
- 중복 판단과 Event 통합은 재처리해도 일관된 결과를 내도록 설계한다.

## Alternatives Considered

1. **기사·문서 중심 모델**: 수집은 단순하지만 중복 노출, 분석 반복과 사건 단위 추적 문제가 크다.
2. **Entity별 뉴스 피드**: 사용자 탐색은 쉽지만 동일 사건이 Entity마다 복제되고 영향 분석과 사실을 혼합하기 쉽다.
3. **모든 정보를 자유 형식 AI 요약으로 통합**: 빠르게 보이지만 재현성, 근거 추적과 비용 통제가 어렵다.

## Consequences

- 사건 식별과 중복 제거가 핵심 품질 요소가 된다.
- 하나의 Event가 여러 Evidence와 Entity를 연결하므로 관계 관리가 필요하다.
- 공통 Event와 분석을 재사용하여 중복 알림과 AI 비용을 줄일 수 있다.
- 잘못 통합된 Event를 분리하거나 누락된 Event를 병합할 수 있는 운영 절차가 필요하다.
