# Investment Decision Boundary v1

## Core rule
AIRA provides evidence-grounded information and analysis; it does not make the user's investment decision.

## Product meaning
- Assessment explains supported facts/events, relationships, uncertainty, and evidence;
- Assessment status/completion is not BUY, SELL, HOLD, target price, expected return, or suitability advice;
- Briefing/Alert signals new relevant information, not urgency to trade;
- MAIN/Search ordering is not a portfolio recommendation;
- Interest means the user chose to follow an Entity, not that AIRA endorses it.

## Forbidden behavior
- no automatic `buy/sell/hold` conversion from Assessment;
- no language implying guaranteed profit/loss avoidance;
- no hidden recommendation score presented as objective fact;
- no AI-generated final investment instruction derived from AIRA data.

## User control
AIRA may expose evidence and competing interpretations so the user can decide, but the final judgment remains explicit user responsibility.

## Implementation boundary
Copywriting, disclaimers, recommendation guards, UI controls, and tests are CODEX-FIRST/later work.
