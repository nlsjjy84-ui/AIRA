# Current / Historical Comparison Boundary v1

## Core rule
Current and Historical Exact are distinct assessment contexts. AIRA may compare them, but must never collapse one into the other.

## Historical Exact
- anchored to an explicit historical Event/Evidence/period context;
- must preserve the exact period and evidence available for that historical statement;
- later corrections or newer information do not silently rewrite the historical view.

## Current
- represents the latest valid current assessment context under explicit supersession/current-selection rules;
- must not be described as what was known at an earlier historical date.

## Comparison
When Current and Historical Exact are shown together, surface:
- which context each side represents;
- their respective evidence/period timestamps;
- whether later Evidence or supersession explains the difference.

## Forbidden behavior
Do not compare a current assessment with a historical one as if both were produced from the same information set.

## Implementation boundary
Comparison queries, snapshots, UI layouts, navigation, and tests are CODEX-FIRST/later work.
